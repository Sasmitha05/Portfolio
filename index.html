August Attic - Fan Merch Shop Demo

Project Overview:

August Attic is a comprehensive e-commerce platform specifically designed for music fans to discover and purchase Taylor swift's merchandise. The platform combines the shopping experience with music discovery through Spotify integration.

Key Features:

  • 🛒 Full-stack e-commerce platform built with MERN Stack
  • 🎵 Integrated Spotify API for music streaming while shopping
  • ☁️ Cloudinary integration for optimized image storage and delivery
  • 👤 User authentication and profile management
  • 🛍️ Shopping cart functionality

Technical Implementation:

Frontend: React.js with modern hooks, Redux for state management, Material-UI for components

Backend: Node.js with Express.js, JWT authentication, RESTful API design

Database: MongoDB with Mongoose ODM for data modeling

External APIs: Spotify Web API, Cloudinary API

Animation System: Optimized GIF rendering with smooth transitions

Backend Processing: Node.js for text processing and gesture mapping

Movie Watchlist App Demo

Project Overview:

A modern React-based movie tracking application that enables users to manage their personal movie watchlist with real-time search, custom categorization, and persistent local storage.

Key Features:

  • 🎬 Add movies to Watchlist or Watched sections with a single click
  • 📂 Two-panel layout: "Watchlist" and "Watched"
  • 🗑️ Remove movies
  • 💾 Persistent storage using browser's LocalStorage
  • ⚙️ Global state management using React Context API

Technical Implementation:

Framework: React.js with functional components and hooks

State Management: Context API with useReducer for scalable global state

API Integration: OMDb API for fetching movie data (title, poster, year)

Persistence: LocalStorage for maintaining user data across sessions

Architecture: Component-based design with separation of concerns

Deployment: Easily deployable to GitHub Pages or Netlify
